# Student Management System

A simple and efficient Student Management System built using Python. It helps to manage student records like adding, viewing, updating, and deleting student data.

## Tech Stack
- Python
- JSON for data storage
- HTML, CSS (Frontend folder)
- Object-Oriented Programming (student.py)

## How to Run
1. Clone the repository:
   git clone https://github.com/rishitha-nimmala/Student-Management-System-.git

2. Run the project:
   python main.py

3. Student data will be saved in students.json file.

## Features
- Add new student details
- View all students list
- Update student information
- Delete student record
- Search student by ID
- Data stored in JSON format

## Project Structure
- main.py - Main execution file
- student.py - Student class logic
- students.json - Database file
- frontend/ - Frontend files
- __pycache__/ - Python cache
